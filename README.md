# GIM_Spreadsheet_Script
This is a side project for my group where we are playing a game.
## Overview
The objective of tihs program is to make our experience while playing RuneScape more enjorable on our new accounts.
While these will be avaliable on this github, please be aware that this is my first time working with this particular programming language. 
This was not done for any organization, or major project in mind. Most if not all of the code provided was created quickly to perform a set task. I have only slightly updated them bit by bit to have them reusable to not create redundant repeated code. 
### How it works
These programs are designed with google spreadsheet in mind. Due to not providing many of the features that MicroSoft Excel provides, I have decided to create a couple of scripts that run on one another in order to perform some tasks automatically. Other programs were created to make goals for us to try to achieve.
